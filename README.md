# StudyMind AI — Mobile Starter

This is a phone-friendly starter project for building an Android app with Capacitor.

## GitHub setup
1. Create a new GitHub repository.
2. Upload all files/folders from this project.
3. Make sure `.github/workflows/build-apk.yml` is included.
4. Open GitHub → Actions → Build Android APK → Run workflow.
5. After it finishes, open the workflow run and download the APK artifact.

## Next
The starter currently has a simple topic-to-notes screen. It can later be expanded with Gemini API, Firebase login, saved notes, flashcards, MCQs and a mind map.
